## التقنيات

Laravel 13 · PHP 8.4 · PostgreSQL 17 · Filament 5 (لوحة إدارة عربية RTL)

## التشغيل على جهاز المطوّر

```bash
composer install
cp .env.example .env && php artisan key:generate
# أنشئ قاعدتي بيانات PostgreSQL: subs و subs_test، ثم:
php artisan migrate --seed                 # البيانات الأساسية + حساب المدير
php artisan db:seed --class=DemoSeeder     # بيانات تجريبية (اختياري، لا تستخدمها على النظام الحقيقي)
php artisan serve
```

افتح `http://127.0.0.1:8000` وادخل باسم المستخدم `admin` وكلمة المرور الموجودة في `ADMIN_PASSWORD` داخل `.env`.

## التسجيل عبر أوامر واتساب

يمكن للمدير/الموظف تسجيل مشترك جديد أو إضافة حساب (يوزر) عن طريق إرسال أوامر نصية إلى رقم واتساب بزنس، عبر **Meta Cloud API (WhatsApp Business API)**.

### الأوامر المتاحة

| الأمر | الوظيفة |
|-------|---------|
| `تسجيل` | تسجيل مشترك جديد (يطلب الاسم، الهاتف، العنوان خطوة بخطوة) |
| `حساب` | إضافة حساب (يوزر) لمشترك موجود |
| `تفعيل [الاسم] 30 يوم` | تفعيل اشتراك وتسجيل دين **أولي** |
| `تفعيل [الاسم] 7 أيام` | تفعيل اشتراك وتسجيل دين **ثانوي** |
| `حالة` | عرض حالة مشترك (بكوده أو هاتفه) |
| `تفويض` | تفويض رقم موظف جديد (للمدير فقط) |
| `إلغاء` | إلغاء العملية الحالية |
| `مساعدة` | عرض قائمة الأوامر |

### الإعداد

1. **أضف المتغيرات إلى `.env`:**

   ```env
   WHATSAPP_TOKEN=           # Access Token من Meta for Developers
   WHATSAPP_PHONE_ID=        # Phone Number ID
   WHATSAPP_VERIFY_TOKEN=    # توكن التحقق من الـ Webhook (اختر أي قيمة)
   WHATSAPP_APP_SECRET=      # App Secret (اختياري، للتحقق من التوقيع)
   ```

2. **شغّل الهجرة (migration):**

   ```bash
   php artisan migrate
   ```

3. **أضف رقم المدير المصرح له** (عدّل الأرقام في الملف ثم شغّل):

   ```bash
   php artisan db:seed --class=WhatsAppAuthorizedUserSeeder
   ```

   أو أضف الرقم يدوياً في جدول `whatsapp_authorized_users`.

4. **سجّل الـ Webhook في Meta for Developers:**
   - Callback URL: `https://your-domain.com/api/whatsapp/webhook`
   - Verify Token: نفس قيمة `WHATSAPP_VERIFY_TOKEN`
   - اشترك في حدث `messages`

5. **أرسل «مساعدة»** من رقم المصرح له لبدء استخدام الأوامر.

### ملاحظات أمنية

- فقط الأرقام المضافة في جدول `whatsapp_authorized_users` تستطيع إرسال الأوامر.
- كلمة السر (الباسورد) تُخزَّن مشفّرة (نفس نظام التشفير المستخدم في اللوحة).
- يُنصح بتفعيل `WHATSAPP_APP_SECRET` للتحقق من توقيع الرسائل الواردة.

### دعم الرسائل الصوتية

يمكن للموظف إرسال الأوامر **صوتياً** أيضاً. يُحوَّل الصوت إلى نص عبر **OpenAI Whisper** ثم يُعالج كنص.

- أضف `WHATSAPP_OPENAI_KEY` في `.env` (مفتاح OpenAI API).
- إذا لم يُضبط المفتاح، تُرفض الرسائل الصوتية برسالة تطلب الإرسال نصياً.
- الرسائل الصوتية تُحوَّل للغة العربية (`language=ar`).
