# المرحلة 6 — الشاشات والوظائف

**مبادئ الواجهة:** عربية RTL، أرقام المبالغ بفواصل الآلاف (`35,000 د.ع`)، بحث عام في الأعلى في كل صفحة (اختصار `/`)، أزرار العمليات السريعة (تفعيل، قبض، مناقلة) متاحة من صفحة المشترك مباشرة، والنماذج قصيرة بقيم افتراضية ذكية. تعمل على شاشة الحاسوب والموبايل.

## 6.2 تفاصيل الشاشات

### 1. لوحة التحكم
- بطاقات اليوم: المقبوضات (نقدي / إلكتروني)، عدد التفعيلات، **إجمالي الديون الثانوية**، **إجمالي الديون الأولية**، رصيد القاصة.
- قائمة **«7 أيام تنتهي اليوم أو غداً»** و**«منتهية غير مكتملة»**، مع زري «قبض» و«مناقلة» لكل سطر.
- قائمة «اشتراكات تنتهي خلال 3 أيام» للتجديد.
- آخر عمليات الموظف الحالي.
- تنبيهات المدير: فروقات المطابقة الليلية، تعارضات المزامنة.

### 2. المشتركون
- جدول: الرقم، الاسم، الهاتف، عدد الحسابات، إجمالي الدين، أقرب انتهاء، الحالة.
- بحث فوري بالاسم (جزئي ومطبَّع)، أو الهاتف بأي صيغة، أو رقم المشترك، أو اليوزر، أو السيريال، أو رقم السند.
- فلاتر: الحالة، عليه دين، منتهي الاشتراك، الفرع.
- إضافة مشترك: نموذج واحد يضيف المشترك **وحسابه الأول** معاً، مع تحذير إذا كان الهاتف موجوداً مسبقاً.

### 3. ملف المشترك (الشاشة الأهم)
- **الرأس:** الاسم، الهاتف (زر اتصال أو واتساب)، العنوان، الحالة، الملاحظات. **الرصيد الإجمالي** (ثانوي / أولي / مقدم).
- **بطاقة لكل حساب:** اليوزر، الباسورد (مخفي، وزر «إظهار» مسجَّل في التدقيق)، السيريال، الفات، العامود، الفئة، حالة التفعيل ونهايته مع عدّاد الأيام المتبقية، دين الحساب. أزرار: **تفعيل**، **قبض**، **مناقلة**، **إضافة جهاز**.
- **تبويبات:** التفعيلات · الديون · السندات · المناقلات · الأجهزة · كشف الحساب · **الخط الزمني** (كل ما حدث من سجل التدقيق).
- إجراءات إدارية: دين يدوي، أرشفة، ودمج مشتركين مكررين (مستقبلاً).

### 4. الحسابات
- جدول كل الحسابات مع البحث باليوزر أو السيريال أو الفات أو العامود، وفلتر «منتهي» و«ينتهي خلال N يوماً» و«بلا تفعيل».
- مفيد للفني: فلترة حسب الفات أو العامود لمعرفة المشتركين على نقطة معيّنة.

### 5. التفعيلات
- **نموذج التفعيل:** الحساب ← الفئة (السعر يظهر تلقائياً) ← النوع (7 أو 30 يوماً) ← العرض (قائمة المنطبق فقط) ← وقت البداية (الآن، قابل للتعديل) ← التسوية (لـ30 يوماً فقط). **معاينة قبل الحفظ:** البداية والنهاية الفعليتان، السعر النهائي، الدين الناتج، وتنبيه الطابور إن وُجد.
- **تبويب «متابعة الـ7 أيام»:** كل `pending` مرتبة حسب الأقرب انتهاءً، ملوّنة (فعّال / ينتهي اليوم / منتهٍ). إجراء جماعي: مناقلة عدة حسابات دفعة واحدة.
- السجل: فلاتر التاريخ، الموظف، الفئة، النوع، العرض، التواريخ المعدّلة.

### 6. الديون
- تبويبات **الثانوية / الأولية / الكل / الملغاة**، مع الإجمالي في أعلى كل تبويب.
- أعمدة: الرقم، المشترك، الحساب، المصدر، الأصل، المسدد، المتبقي، التاريخ، العمر بالأيام، الحالة.
- صفحة الدين: التفاصيل، التسديدات، المناقلات، والقيود. زر «إلغاء» (بصلاحية وسبب).

### 7. القبض والسندات
- **نموذج القبض:** الحساب ← النوع ← الطريقة ← الصندوق أو المحفظة (والمستلم للإلكتروني) ← المبلغ ← الديون (اختيار أو FIFO) ← **معاينة التوزيع** (ومنها «سيكمل تفعيل 7 أيام +23 يوماً») ← حفظ ← **عرض السند** مع زري طباعة وPDF.
- سجل السندات: بحث برقم السند، وفلاتر التاريخ، الموظف، الطريقة، الصندوق. الملغى يظهر مشطوباً.

### 8. المناقلات
- إنشاء من ملف المشترك أو من متابعة الـ7 أيام. **تأكيد يعرض:** المبلغ المنقول، الأيام المضافة، النهاية الجديدة، وتذكير «مدِّد على موقع الشركة».
- السجل مع الفلاتر، وإلغاء بصلاحية.

### 9. المصروفات
- نموذج: الفئة، المبلغ، الصندوق، الجهة، الوصف، التاريخ. السجل مع الإجمالي حسب الفئة.

### 10. المبيعات
- نموذج: المادة (النوع، الوصف، السيريال)، المشتري (مشترك أو اسم حر)، السعر، الكلفة (أو ربط بمصروف شراء)، نقداً أو آجلاً. إنشاء سجل جهاز تلقائياً اختياري. السجل مع الربح لكل بيع.

### 11. الصناديق والمحافظ
- رصيد كل قاصة ومحفظة الآن، وحركاتها بالتفصيل، والرصيد الابتدائي (للمدير).

### 12. الأجهزة
- قائمة الأجهزة مع البحث بالسيريال أو الـ MAC، والحالة، والملكية. صفحة الجهاز: البيانات، الحقول المرنة، **سجل الملاحظات الفنية** (للإضافة فقط).

### 13. التقارير
- قائمة التقارير R1–R11 ([04-business-logic.md §4.9](04-business-logic.md))، بفلاتر موحدة وتصدير. التقرير اليومي يُفتح افتراضياً على اليوم الحالي.

### 14. الاستيراد والمزامنة
- المصادر، ورفع ملف مع **ربط الأعمدة** (Mapping) وحفظ الربط للمرات القادمة.
- الدفعات: الحالة والإحصاءات. صفحة الدفعة: تبويبات جديد / معدّل / تعارض / مفقود / أخطاء، مع زر «تطبيق» وحل التعارضات حقلاً بحقل، و«إعادة محاولة الفاشل».
- تقرير المطابقة مع موقع الشركة.

### 15. المستخدمون والصلاحيات
- المستخدمون: إضافة، تعطيل، إعادة تعيين كلمة المرور، الجلسات النشطة وإنهاؤها.
- الأدوار: مصفوفة صلاحيات بمربعات اختيار. صلاحيات مباشرة لمستخدم معيّن.

### 16. سجل العمليات
- جدول: الوقت، المستخدم، العملية، السجل المتأثر (رابط)، المصدر. فلاتر المستخدم، العملية، الكيان، الفترة. تفاصيل تعرض **القيمة القبلية والبعدية** جنباً إلى جنب. للقراءة فقط.
