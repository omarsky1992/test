# رفع النظام على الإنترنت وفتحه من الموبايل

النظام **موقع ويب**: تفتحه من أي متصفح (حاسوب أو موبايل) على عنوان مثل `https://subs.example.com`. ويمكن **تثبيته على شاشة الهاتف** فيظهر كتطبيق بأيقونة، بدون متجر تطبيقات.

## ماذا تحتاج؟

| الشيء | الوصف | ملاحظة |
|-------|-------|--------|
| **خادم سحابي (VPS)** | جهاز على الإنترنت يعمل 24 ساعة. أي مزود: Hetzner، DigitalOcean، Contabo، Vultr… | يكفي خادم صغير: 2 معالج، 2–4 GB ذاكرة، Ubuntu 24.04 |
| **نطاق (دومين)** | عنوان الموقع، مثل `mycompany-net.com` | من أي مسجّل نطاقات (Namecheap، GoDaddy، Cloudflare…) |
| **ربع ساعة** | لتنفيذ الخطوات أدناه مرة واحدة | أو أعطِ هذه الصفحة لأي مبرمج |

> 💡 **بديل أسهل بدون خادم:** خدمات مثل **Laravel Cloud** تربط المستودع مباشرة من GitHub وتدير الخادم وقاعدة البيانات والنسخ الاحتياطي عنك (باشتراك شهري). اختر PostgreSQL كقاعدة بيانات، وأضف متغيرات البيئة من `deploy/.env.example`.

## الخطوات على خادم VPS

### 1. اربط النطاق بالخادم
في لوحة النطاق أضف سجل **A**: الاسم `subs` (أو `@`)، والقيمة = عنوان IP الخادم.

### 2. ثبّت Docker على الخادم
ادخل على الخادم (SSH) ونفّذ:
```bash
curl -fsSL https://get.docker.com | sh
```

### 3. انسخ النظام وجهّز الإعدادات
```bash
git clone https://github.com/omarsky1992/test.git subs && cd subs/deploy
cp .env.example .env
nano .env
```
عدّل داخل الملف:
- `APP_DOMAIN` و`APP_URL`: عنوان موقعك، مثل `subs.mycompany-net.com`.
- `APP_KEY`: ضع الناتج من الأمر `echo base64:$(openssl rand -base64 32)`.
- `DB_PASSWORD`: كلمة سر قوية لقاعدة البيانات.
- `ADMIN_PASSWORD`: كلمة سر المدير لأول دخول.

### 4. شغّل النظام
```bash
docker compose --env-file .env up -d --build
docker compose exec app php artisan db:seed --force
```
- الأمر الأول يبني النظام ويشغّل قاعدة البيانات، ويستخرج شهادة HTTPS تلقائياً (القفل الأخضر).
- الأمر الثاني ينشئ البيانات الأساسية (الفئات الأربع، الصناديق، الصلاحيات) وحساب المدير.

افتح `https://subs.mycompany-net.com` وادخل باسم المستخدم `admin` وكلمة المرور التي وضعتها.

### 5. أول إعداد داخل النظام
1. **الإعدادات:** اسم الوكيل وعنوانه وهاتفه (تظهر في السند).
2. **الصناديق ورصيد الشركة:** أدخل **الرصيد الابتدائي** للقاصة، وأدخل رصيدكم الحالي على موقع الشركة. أضف المحافظ الإلكترونية (زين كاش…).
3. **المستخدمون:** أضف الموظفين بدور «موظف». ولمن تريد، امنحه صلاحيات إضافية مثل «حذف الدين».
4. **الديون القائمة:** سجّلها كـ «دين يدوي ← افتتاحي» لكل حساب.
5. **التفعيلات السارية:** سجّلها بوقت بدايتها الحقيقي، حتى تعمل التنبيهات من اليوم الأول.

## تثبيته على الموبايل كتطبيق

- **أندرويد (Chrome):** افتح الموقع ← القائمة ⋮ ← **إضافة إلى الشاشة الرئيسية** (أو «تثبيت التطبيق»).
- **آيفون (Safari):** افتح الموقع ← زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية**.

تظهر أيقونة «المشتركين» على الشاشة، وتفتح النظام بملء الشاشة. النظام يحتاج إنترنت دائماً، لأن البيانات المالية يجب أن تكون حيّة من الخادم.

## التحديث عند نزول نسخة جديدة
```bash
cd subs && git pull && cd deploy
docker compose --env-file .env up -d --build
```
التحديثات على قاعدة البيانات تُطبَّق تلقائياً عند التشغيل.

## النسخ الاحتياطي
- تُحفظ نسخة يومية تلقائياً من قاعدة البيانات في `deploy/backups`: آخر 7 أيام، و4 أسابيع، و6 أشهر.
- **مهم:** انسخ مجلد `backups` دورياً إلى مكان خارج الخادم (Google Drive أو حاسوبك). إذا تعطّل الخادم نفسه، تبقى النسخة معك.
- الاسترجاع من نسخة:
  ```bash
  gunzip -c backups/daily/subs-XXXX.sql.gz | docker compose exec -T db psql -U subs -d subs
  ```

## الأمان
- غيّر كلمة سر المدير بعد أول دخول، ولا تشارك حساب المدير.
- كل موظف له حساب خاص، حتى يُسجَّل اسمه على عملياته.
- عند ترك موظف للعمل: **عطّل** حسابه (لا تحذفه)، فتنتهي جلساته فوراً ويبقى اسمه على عملياته السابقة.
